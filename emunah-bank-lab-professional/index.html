Blueprint / Visão Geral

00 · VISÃO GERAL

O que é o EMUNAH-BANK-LAB?

Um laboratório de aplicações mainframe com cara de ambiente bancário real. O foco é praticar o ciclo completo: preparar massa, validar lançamentos, postar movimentos, consolidar saldos, gerar extrato, conciliar e fechar o dia.

Visão oficial do projeto: o lab principal usa IBM Z Xplore e não depende de emulador local. Hercules/TK4- entram como trilha paralela de estudo, não como base oficial da execução atual.

COBOL + JCL

Programas batch com regras de negócio bancárias, build via IGYWCL e execução por jobs.

VSAM + GDG

Cadastro e arquivos operacionais em KSDS, ESDS e histórico de extrato em geração.

Zowe + TN3270

Publicação local, submissão de jobs, análise de spool e operação em ISPF/SDSF.

Runbook + Review

Além do blueprint, o projeto já documenta incidentes, bugs e caminhos de correção.

03 · GRADE BATCH

Cadeia diária recomendada

Fluxo operacional com dependências explícitas e papéis claros para cada job.

06:00  PRECHECK  -> valida datasets críticos
06:15  EBSEED    -> carga inicial (somente setup)
06:30  EBJLOAD   -> verifica recebimento do arquivo do dia
07:00  EBJVALD   -> separa válidos e rejeitos
07:30  EBJPOST   -> aplica lançamentos válidos
08:00  EBJSALD   -> consolida saldos
09:00  EBJEXTR   -> gera extrato
09:30  EBJCONC   -> concilia totais
10:00  EBJEOD    -> fechamento operacional do dia
Sob demanda: EBJREPR -> reprocessa rejeitos corrigidos

Bloqueio 1

Sem arquivo de entrada, a cadeia precisa parar em EBJLOAD.

Bloqueio 2

RC alto em EBJVALD impede a postagem do lote.

Bloqueio 3

Conciliação divergente bloqueia o fechamento do dia.

M4 · BUILD E COMPILAÇÃO

Compilar e gerar executáveis

Para o dia a dia, o caminho mais prático é usar EBBUILD com a procedure IGYWCL.

JCL 
//* --------------------------------------------------------------
 //* EBBUILD — compile + link em uma única execução
 //* Uso: troque o membro EBCLLOAD pelo programa desejado
 //* Saída: módulo carregável em Z77948.EMUNAH.DEV.LOADLIB
 //* --------------------------------------------------------------
//EBBUILD  JOB ,'EMUNAH BUILD',CLASS=A,MSGCLASS=X,MSGLEVEL=(1,1)
//CL       EXEC IGYWCL
//COBOL.SYSIN   DD DSN=Z77948.EMUNAH.DEV.COBOL(EBCLLOAD),DISP=SHR
//COBOL.SYSLIB  DD DSN=Z77948.EMUNAH.DEV.COPY,DISP=SHR
//LKED.SYSLMOD  DD DSN=Z77948.EMUNAH.DEV.LOADLIB(EBCLLOAD),DISP=SHR
//LKED.SYSPRINT DD SYSOUT=*
//*
PowerShell 
param([string]$Pgm = "EBCLLOAD")
$HQ = "Z77948.EMUNAH"

$jcl = @"
//EBBUILD  JOB ,'EB $Pgm',CLASS=A,MSGCLASS=X,MSGLEVEL=(1,1)
//CL       EXEC IGYWCL
//COBOL.SYSIN   DD DSN=$HQ.DEV.COBOL($Pgm),DISP=SHR
//COBOL.SYSLIB  DD DSN=$HQ.DEV.COPY,DISP=SHR
//LKED.SYSLMOD  DD DSN=$HQ.DEV.LOADLIB($Pgm),DISP=SHR
//LKED.SYSPRINT DD SYSOUT=*
//*
"@

$tmp = ".\jcl\temp\BUILD_$Pgm.jcl"
$jcl | Out-File -FilePath $tmp -Encoding ascii
zowe zos-files upload file-to-data-set $tmp "$HQ.DEV.JCL(EBBUILD)"
zowe zos-jobs submit data-set "$HQ.DEV.JCL(EBBUILD)"

# check_env.ps1 — valida datasets críticos antes da cadeia batch
$HQ = "Z77948.EMUNAH"
$datasets = @(
  "$HQ.ARQ.ENTRADA.SEQ",
  "$HQ.ARQ.CLIENTE.KSDS",
  "$HQ.ARQ.CONTA.KSDS",
  "$HQ.ARQ.LANCTO.ESDS",
  "$HQ.ARQ.REJEITO.SEQ",
  "$HQ.ARQ.AUDIT.SEQ",
  "$HQ.ARQ.SALDO.KSDS",
  "$HQ.ARQ.EXTRATO.GDG",
  "$HQ.DEV.LOADLIB"
)

$ok = 0
$fail = 0

foreach ($ds in $datasets) {
  $result = zowe zos-files list data-set $ds 2>&1
  if ($LASTEXITCODE -eq 0) {
    Write-Host "[OK]  $ds" -ForegroundColor Green
    $ok++
  } else {
    Write-Host "[ERR] $ds" -ForegroundColor Red
    $fail++
  }
}

Write-Host ""
Write-Host "Resumo: $ok OK / $fail faltando"
if ($fail -gt 0) {
  Write-Host "Corrija antes da execução." -ForegroundColor Yellow
}

COBOL — EBCLLOAD comentado

COBOL 
      ******************************************************************
      * PROGRAMA : EBCLLOAD                                            *
      * FINALIDADE: carregar massa inicial de clientes e contas        *
      * ENTRADAS  : CLIENTIN e CONTAIN                                 *
      * SAÍDAS    : CLIENTE-KSDS, CONTA-KSDS e AUDIT-OUT               *
      * OBSERVAÇÃO: usar OPEN OUTPUT na carga inicial                  *
      ******************************************************************
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EBCLLOAD.

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT CLIENTE-IN  ASSIGN TO CLIENTIN
               ORGANIZATION IS LINE SEQUENTIAL.
           SELECT CONTA-IN    ASSIGN TO CONTAIN
               ORGANIZATION IS LINE SEQUENTIAL.
           SELECT AUDIT-OUT   ASSIGN TO AUDIT
               ORGANIZATION IS LINE SEQUENTIAL.
           SELECT CLIENTE-KSDS ASSIGN TO CLIENTE
               ORGANIZATION IS INDEXED
               ACCESS MODE  IS SEQUENTIAL
               RECORD KEY   IS CLI-ID
               FILE STATUS  IS WS-FS-CLI.
           SELECT CONTA-KSDS ASSIGN TO CONTA
               ORGANIZATION IS INDEXED
               ACCESS MODE  IS SEQUENTIAL
               RECORD KEY   IS CNT-CHAVE
               FILE STATUS  IS WS-FS-CNT.

       DATA DIVISION.
       FILE SECTION.
       FD CLIENTE-IN.
       01 REG-CLIENTE-IN          PIC X(63).

       FD CONTA-IN.
       01 REG-CONTA-IN            PIC X(41).

       FD AUDIT-OUT.
       01 REG-AUDIT               PIC X(120).

       FD CLIENTE-KSDS.
       01 REG-CLIENTE.
          COPY CPCLI001.

       FD CONTA-KSDS.
       01 REG-CONTA.
          COPY CPCNT001.

       WORKING-STORAGE SECTION.
       01 WS-FS-CLI               PIC XX.
       01 WS-FS-CNT               PIC XX.
       01 WS-QTD-CLIENTES         PIC 9(7) VALUE ZERO.
       01 WS-QTD-CONTAS           PIC 9(7) VALUE ZERO.

       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           OPEN INPUT  CLIENTE-IN
           OPEN INPUT  CONTA-IN
           OPEN OUTPUT CLIENTE-KSDS
           OPEN OUTPUT CONTA-KSDS
           OPEN OUTPUT AUDIT-OUT

           PERFORM 1000-CARREGA-CLIENTES
           PERFORM 2000-CARREGA-CONTAS
           PERFORM 9000-FINALIZA
           GOBACK.

       1000-CARREGA-CLIENTES.
           READ CLIENTE-IN
               AT END
                   EXIT PARAGRAPH
           END-READ
           PERFORM UNTIL 1 = 2
               MOVE REG-CLIENTE-IN(1:5)   TO CLI-ID
               MOVE REG-CLIENTE-IN(6:30)  TO CLI-NOME
               MOVE REG-CLIENTE-IN(36:11) TO CLI-CPF
               WRITE REG-CLIENTE
                   INVALID KEY
                       MOVE 'CLIENTE DUPLICADO' TO REG-AUDIT
                       WRITE REG-AUDIT
                   NOT INVALID KEY
                       ADD 1 TO WS-QTD-CLIENTES
               END-WRITE
               READ CLIENTE-IN
                   AT END EXIT PERFORM
               END-READ
           END-PERFORM.

       2000-CARREGA-CONTAS.
           READ CONTA-IN
               AT END
                   EXIT PARAGRAPH
           END-READ
           PERFORM UNTIL 1 = 2
               MOVE REG-CONTA-IN(1:4)   TO CNT-AGENCIA
               MOVE REG-CONTA-IN(5:8)   TO CNT-NUM-CONTA
               MOVE REG-CONTA-IN(13:5)  TO CNT-CLI-ID
               MOVE REG-CONTA-IN(18:1)  TO CNT-TIPO
               MOVE REG-CONTA-IN(19:1)  TO CNT-STATUS
               MOVE REG-CONTA-IN(20:13) TO CNT-SALDO
               WRITE REG-CONTA
                   INVALID KEY
                       MOVE 'CONTA DUPLICADA' TO REG-AUDIT
                       WRITE REG-AUDIT
                   NOT INVALID KEY
                       ADD 1 TO WS-QTD-CONTAS
               END-WRITE
               READ CONTA-IN
                   AT END EXIT PERFORM
               END-READ
           END-PERFORM.

       9000-FINALIZA.
           STRING 'CLIENTES=' WS-QTD-CLIENTES
                  ' CONTAS='  WS-QTD-CONTAS
             DELIMITED BY SIZE
             INTO REG-AUDIT
           END-STRING
           WRITE REG-AUDIT
           CLOSE CLIENTE-IN CONTA-IN CLIENTE-KSDS CONTA-KSDS AUDIT-OUT.

COBOL — EBVALI01 comentado

COBOL 
      ******************************************************************
      * PROGRAMA : EBVALI01                                            *
      * FINALIDADE: validar layout e regra de negócio dos lançamentos  *
      * ENTRADA   : ENTRADA                                            *
      * SAÍDAS    : VALIDOS e REJEITOS                                 *
      ******************************************************************
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EBVALI01.

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT MOVTO-IN    ASSIGN TO ENTRADA
               ORGANIZATION IS LINE SEQUENTIAL.
           SELECT VALID-OUT   ASSIGN TO VALIDOS
               ORGANIZATION IS SEQUENTIAL.
           SELECT REJECT-OUT  ASSIGN TO REJEITOS
               ORGANIZATION IS SEQUENTIAL.

       DATA DIVISION.
       FILE SECTION.
       FD MOVTO-IN.
       01 REG-IN                PIC X(120).

       FD VALID-OUT.
       01 REG-VALIDO            PIC X(120).

       FD REJECT-OUT.
       01 REG-REJEITO           PIC X(120).

       WORKING-STORAGE SECTION.
       01 WS-QTD-VALIDOS        PIC 9(7) VALUE ZERO.
       01 WS-QTD-REJEITOS       PIC 9(7) VALUE ZERO.
       01 WS-TIPO               PIC X.
       01 WS-VALOR              PIC 9(13).

       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           OPEN INPUT MOVTO-IN
           OPEN OUTPUT VALID-OUT
           OPEN OUTPUT REJECT-OUT

           PERFORM 1000-PROCESSA UNTIL 1 = 2
           CLOSE MOVTO-IN VALID-OUT REJECT-OUT
           GOBACK.

       1000-PROCESSA.
           READ MOVTO-IN
               AT END EXIT PERFORM
           END-READ

           MOVE REG-IN(21:1)  TO WS-TIPO
           MOVE REG-IN(22:13) TO WS-VALOR

           IF WS-TIPO NOT = 'C' AND
              WS-TIPO NOT = 'D'
               MOVE REG-IN TO REG-REJEITO
               WRITE REG-REJEITO
               ADD 1 TO WS-QTD-REJEITOS
           ELSE
               MOVE REG-IN TO REG-VALIDO
               WRITE REG-VALIDO
               ADD 1 TO WS-QTD-VALIDOS
           END-IF.

A · BUGS CRÍTICOS

Checklist do que quebra a cadeia

Itens marcáveis com persistência local no navegador.

0 / 0 resolvidos

EBJVALD sem DD VALIDOS / REJEITOS alinhados

O COBOL espera ASSIGN TO VALIDOS e REJEITOS. Se o JCL não casar os nomes, ocorre erro de OPEN.

EBJPOST lendo entrada errada

EBPOST01 deve consumir LANCTO.ESDS (movimentos válidos), não o arquivo bruto de entrada.

EBJCONC sem CONCOUT

A conciliação precisa de saída própria para evidência, auditoria e bloqueio do fechamento.

Seeds e copybooks desalinhados

Qualquer divergência entre layout físico e copybook derruba carga, leitura ou interpretação dos registros.

B · INCONSISTÊNCIAS

Pontos que confundem operação e manutenção

Não necessariamente derrubam tudo, mas geram ruído e retrabalho.

0 / 0 resolvidos

Trilha oficial misturada com trilha alternativa

Hercules/TK4- e IBM Z Xplore precisam ficar claramente separados na documentação.

EBBUILD, EBCOMP e EBLINK com papéis duplicados
