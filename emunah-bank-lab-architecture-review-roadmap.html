Compile Fixes Applied — EBREJDB1
  • IGYDS1064-E fixed: Removed REDEFINES REJEITO-REG from 01 LANCTO-ORIG in FILE SECTION. Multiple 01s under the same FD share the I/O buffer implicitly — the REDEFINES clause is syntactically illegal at level-01 in FILE SECTION.
  • IGYCB7309/7310-W fixed: Moved blank-record guard (REJ-COD-MOTIVO = SPACES) out of 2100-LER-REJEITO and into 2000-PROCESSAR-REJEITOS as an IF/ELSE. Eliminated the self-recursive PERFORM 2100-LER-REJEITO inside the same paragraph.
  • EBAUDDB1: Same recursive PERFORM pattern present — identical fix needed before upload.
Discovered COBOL Rules (permanent lab knowledge)
  • REDEFINES on a level-01 item in the FILE SECTION is illegal — use implicit co-location (multiple 01s under same FD).
  • A paragraph cannot PERFORM itself — recursion corrupts the return stack; move validation into the calling loop.
  • WITH DEFAULT '' invalid in DB2 for z/OS DDL — use bare WITH DEFAULT.
  • CURRENT_TIMESTAMP → SQLCODE=-104 on Hercules DBD1 — make column nullable instead.
  • COND named-step trap: always bare COND=(4,LT), never COND=(4,LT,stepname).
  • ESDS files: ASSIGN TO AS-ddname prefix required; ORGANIZATION IS SEQUENTIAL; no RECORD KEY.
  • COMPILE PARM: 'APOST,MAP' — no LIB (generates harmless IGYOS4090-I).
  • SYSOUT=*,OUTLIM=500000 on RUN step — prevents S722 on large duplicate runs.

Executive Assessment

The lab is architecturally coherent and well above hobbyist level. The 14-phase EBJCHAIN, the CTL.STATUS state machine, the VSAM enqueue discipline, three-way reconciliation, GDG immutability, and the DEV/HML/PRD promotion model all reflect genuine enterprise patterns. The DB2 layer is now being activated: three tables are loaded (CDCLI, CDCNT, CDLCT), two more (CDREJ, CDAUD) are in flight. Phase 2 close-out will complete the full 6-table VSAM→DB2 loader chain — the first concrete step of the roadmap.

✓ Confirmed Strengths
  • State-machine-guarded batch lifecycle (EBCTL01, CTL.STATUS) mirrors production discipline correctly.
  • CICS window management (EBJCLOSE / EBJOPEN) around the batch chain — correct pattern for VSAM shared-access.
  • GDG-based immutable checkpointing on every output that matters (SALDO, EXTRATO, BKP sets).
  • Reconciliation gate before EBJEOD01 closes the day — a hard business control, not cosmetic.
  • Copybook-driven record layouts throughout — made the DB2 bulk-load chain straightforward to implement.
  • Multi-environment dataset segregation (DEV / HML / PRD) with promotion rules in docs.
  • EBOPS operational simulator — genuinely unique for a study lab and directly marketable on a CV.
  • New: Full VSAM→DB2 loader chain nearing completion: 3 of 6 tables loaded, FK chain verified end-to-end.
⚠ Remaining Gaps
  • CDREJ and CDAUD loaders not yet submitted — compile fixes applied, awaiting re-upload.
  • No embedded SQL in the CICS online programs (EBCSSLD, EBCSTRF) yet — DB2 integration is batch-only.
  • No HLASM at all — Assembly topic completely unexplored.
  • REXX has health-check/job-submission scripts but no RXSQL or JES2 SDSF API patterns.
  • EBOPS runs locally on Python/Flask — USS migration not yet started.
  • No IMS integration despite IMS V15 in the stack.
  • No ISO 8583 or CNAB file simulation for ATM/file-exchange channels.
  • MQ is in the stack but no MQPUT wired in any program yet.

Topic 1 — DB2 Schema & Core Banking Data Model

Current State

Schema has 6 tables: CDCLI (CIF), CDCNT (accounts), CDLCT (movements), CDEXT (extract), CDREJ (rejects), CDAUD (audit). Full FK chain: CDLCT → CDCNT → CDCLI. Identity columns on CDREJ.REJ_ID and CDAUD.AUD_ID. Three tables loaded (160 total rows). Loader chain for CDREJ and CDAUD in flight.

DB2 V13 Features to Add Next

Triggers for GL

Write an AFTER INSERT ON CDLCT FOR EACH ROW trigger that inserts two rows into a new CDGL table (debit leg, credit leg). Simulates the double-entry accounting engine that FlexCube's GL module performs implicitly — and teaches trigger syntax, transition variables, and compound statements.

Stored Procedure: SP_CONSULTA_SALDO

A stored procedure callable from both COBOL batch and CICS. Add a TRUSTED CONTEXT + ROW PERMISSION on CDCNT that restricts access by CURRENT SQLID to simulate branch-level data segregation — the FlexCube CIF restriction model.

Partitioned Tablespace on CDLCT

Rebuild CDLCT in a Partition-by-Range UTS on LCT_DATA. Run RUNSTATS + REORG on a single partition. Teaches the operational lifecycle of a high-volume movement table at lab scale.

Topic 4 — Assembly Language (HLASM)

Recommended Path (Phase 6)

  1. Register linkage: EBASMSUM — receives two PIC 9(8) COMP-4 params via OS CALL (R1→param list, R14=return, R13=save area), returns sum in R0. Call from COBOL. Teaches the full linkage your COBOL hides.
  2. Macro expansion: Write macro EBALOG expanding to a QSAM WRITE sequence. Compare the expansion listing to what COBOL generates for a WRITE.
  3. SVC 99 (DYNALLOC): Dynamically allocate a dataset from Assembly — the underpinning of JCL, Zowe, and REXX ALLOCATE.
  4. Storage display: EBCOREDP — receive address + length, format hex+EBCDIC to SYSOUT. Callable from COBOL via CALL 'EBCOREDP'.

Definition of Done for a COBOL Story

  • Program compiles cleanly — zero MNOTE/E-level diagnostics; RC ≤ 4 with no flow-analysis warnings.
  • EBJSMKH smoke test passes in DEV.
  • Full EBJCHAIN completes RC=0 in HML.
  • CONCIL.SEQ shows no DIVERGENTE rows.
  • Copybook changes are backward-compatible (or migration JCL is written).
  • Change-log case study written in docs/change-log/.
  • EBOPS ticket closed with resolution notes.
