 ISSUES ENCOUNTERED AND RESOLVED
 -------
 Issue 1: COND=(4,LT,stepname) cascade trap
   Cause : Named-step COND skips condition when referenced step
           was itself bypassed. COMPILE failed RC=12 but BINDPKG
           and RUN executed because LKED had no RC to check.
   Fix   : Changed all COND=(4,LT,stepname) to COND=(4,LT).
           Global check — any prior step RC>4 stops the chain.

 Issue 2: FUNCTION NUMVAL on PIC 9(n) fields
   Cause : NUMVAL requires PIC X (character string) arguments.
           CNT-AGENCIA/CNT-NUM-CONTA/CNT-ID-CLIENTE are PIC 9(n)
           DISPLAY numeric — already numeric, no function needed.
           Compiler: IGYPS2292-S / IGYPA3245-S (Severe) RC=12.
   Fix   : Replaced MOVE FUNCTION NUMVAL(field) TO host-var
           with direct MOVE field TO host-var.
           COBOL handles DISPLAY->COMP binary conversion natively.
   Note  : DCLCNT.cpy comment also corrected — it incorrectly
           stated NUMVAL was required.
