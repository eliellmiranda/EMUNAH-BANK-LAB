## Resumo prático

| Grupo | Ferramentas mais importantes |
|---|---|
| **Para entrar em vaga júnior** | Jira, Confluence, TSO/ISPF, Control-M, Changeman, Endevor, SYNCSORT/DFSORT, Git/GitHub |
| **Para evoluir para pleno** | File Manager, Hexavision, ServiceNow, IDCAMS, IDz, ZDT, REXX, CA-7 |
| **Como diferencial** | z/OS Connect, ADDI, IMS Explorer, Expeditor, Abend-Aid, Fault Analyzer, RACF |
