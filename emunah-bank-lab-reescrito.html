Cadeia batch corrigida

A carga inicial foi separada do processamento do dia. O job antigo de carga foi renomeado conceitualmente para EBSEED para não colidir com o papel do EBJLOAD.

SETUP / SOB DEMANDA
  EBSEED  -> carrega clientes e contas a partir dos arquivos SEED

ROTINA DIÁRIA
  EBJLOAD -> precheck do ARQ.ENTRADA.SEQ
  EBJVALD -> valida lote bruto
  EBJPOST -> aplica lançamentos validados
  EBJSALD -> consolida saldo
  EBJEXTR -> gera extrato GDG
  EBJCONC -> concilia totais
  EBJEOD  -> backup + fechamento

COBOL — EBCLLOAD.cbl
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EBCLLOAD.
      *==============================================================*
      * CARGA INICIAL DOS ARQUIVOS DE SEED PARA OS KSDS.             *
      * USAR NA FASE DE SETUP.                                       *
      *==============================================================*

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT CLIENTE-IN ASSIGN TO CLIENTIN.
           SELECT CONTA-IN   ASSIGN TO CONTAIN.
           SELECT CLIENTE-KSDS ASSIGN TO CLIENTE
               ORGANIZATION IS INDEXED
               ACCESS MODE IS DYNAMIC
               RECORD KEY IS CLI-ID.
           SELECT CONTA-KSDS ASSIGN TO CONTA
               ORGANIZATION IS INDEXED
               ACCESS MODE IS DYNAMIC
               RECORD KEY IS CNT-CHAVE.
           SELECT AUDIT-OUT ASSIGN TO AUDIT.

       DATA DIVISION.
       FILE SECTION.
       FD CLIENTE-IN.
       01 REG-CLIENTE-IN.
          COPY CPCLI001.

       FD CONTA-IN.
       01 REG-CONTA-IN.
          COPY CPCNT001.

       FD CLIENTE-KSDS.
       01 REG-CLIENTE.
          COPY CPCLI001.

       FD CONTA-KSDS.
       01 REG-CONTA.
          COPY CPCNT001.

       FD AUDIT-OUT.
       01 REG-AUDIT PIC X(120).

       WORKING-STORAGE SECTION.
       01 WS-FIM-CLI PIC X VALUE 'N'.
       01 WS-FIM-CNT PIC X VALUE 'N'.

       PROCEDURE DIVISION.
       0000-PRINCIPAL.
      * PARA CARGA INICIAL, OPEN OUTPUT E O MAIS SEGURO.
           OPEN INPUT CLIENTE-IN CONTA-IN
                OUTPUT CLIENTE-KSDS CONTA-KSDS AUDIT-OUT

           PERFORM UNTIL WS-FIM-CLI = 'S'
               READ CLIENTE-IN
                   AT END MOVE 'S' TO WS-FIM-CLI
                   NOT AT END
                       MOVE REG-CLIENTE-IN TO REG-CLIENTE
                       WRITE REG-CLIENTE
               END-READ
           END-PERFORM

           PERFORM UNTIL WS-FIM-CNT = 'S'
               READ CONTA-IN
                   AT END MOVE 'S' TO WS-FIM-CNT
                   NOT AT END
                       MOVE REG-CONTA-IN TO REG-CONTA
                       WRITE REG-CONTA
               END-READ
           END-PERFORM

           MOVE 'EBCLLOAD OK' TO REG-AUDIT
           WRITE REG-AUDIT
           CLOSE CLIENTE-IN CONTA-IN CLIENTE-KSDS CONTA-KSDS AUDIT-OUT
           GOBACK.
COBOL — EBVALI01.cbl
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EBVALI01.
      *==============================================================*
      * ENTRADA  : ENTRADA  -> ARQ.ENTRADA.SEQ                       *
      * VALIDOS  : VALIDOS  -> ARQ.LANCTO.ESDS                       *
      * REJEITOS : REJEITOS -> ARQ.REJEITO.SEQ                       *
      *==============================================================*

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT MOVTO-IN  ASSIGN TO ENTRADA.
           SELECT MOVTO-VAL ASSIGN TO VALIDOS.
           SELECT MOVTO-REJ ASSIGN TO REJEITOS.

       DATA DIVISION.
       FILE SECTION.
       FD MOVTO-IN.
       01 REG-MOVTO-IN.
          COPY CPLCT001.

       FD MOVTO-VAL.
       01 REG-MOVTO-VAL.
          COPY CPLCT001.

       FD MOVTO-REJ.
       01 REG-MOVTO-REJ.
          COPY CPLCT001.

       WORKING-STORAGE SECTION.
       01 WS-FIM PIC X VALUE 'N'.

       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           OPEN INPUT MOVTO-IN
                OUTPUT MOVTO-VAL MOVTO-REJ

           PERFORM UNTIL WS-FIM = 'S'
               READ MOVTO-IN
                   AT END MOVE 'S' TO WS-FIM
                   NOT AT END
                       PERFORM 1000-VALIDA
               END-READ
           END-PERFORM

           CLOSE MOVTO-IN MOVTO-VAL MOVTO-REJ
           GOBACK.

       1000-VALIDA.
      * EXEMPLO DIDATICO: ACEITA SOMENTE TIPO C OU D.
           IF LCT-TIPO = 'C' OR LCT-TIPO = 'D'
               MOVE REG-MOVTO-IN TO REG-MOVTO-VAL
               WRITE REG-MOVTO-VAL
           ELSE
               MOVE REG-MOVTO-IN TO REG-MOVTO-REJ
               WRITE REG-MOVTO-REJ
           END-IF.
COBOL — EBPOST01.cbl
       IDENTIFICATION DIVISION.
       PROGRAM-ID. EBPOST01.
      *==============================================================*
      * LE OS MOVIMENTOS VALIDOS E APLICA NAS CONTAS.                *
      * MOVTIN E O DDNAME CORRETO DE ENTRADA.                        *
      *==============================================================*

       ENVIRONMENT DIVISION.
       INPUT-OUTPUT SECTION.
       FILE-CONTROL.
           SELECT MOVTO-IN   ASSIGN TO MOVTIN.
           SELECT CONTA-KSDS ASSIGN TO CONTA
               ORGANIZATION IS INDEXED
               ACCESS MODE IS DYNAMIC
               RECORD KEY IS CNT-CHAVE.
           SELECT AUDIT-OUT  ASSIGN TO AUDIT.

       DATA DIVISION.
       FILE SECTION.
       FD MOVTO-IN.
       01 REG-MOVTO-IN.
          COPY CPLCT001.

       FD CONTA-KSDS.
       01 REG-CONTA.
          COPY CPCNT001.

       FD AUDIT-OUT.
       01 REG-AUDIT PIC X(120).

       WORKING-STORAGE SECTION.
       01 WS-FIM PIC X VALUE 'N'.

       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           OPEN INPUT MOVTO-IN
                I-O CONTA-KSDS
                EXTEND AUDIT-OUT

           PERFORM UNTIL WS-FIM = 'S'
               READ MOVTO-IN
                   AT END MOVE 'S' TO WS-FIM
                   NOT AT END
                       PERFORM 1000-POSTA
               END-READ
           END-PERFORM

           CLOSE MOVTO-IN CONTA-KSDS AUDIT-OUT
           GOBACK.

       1000-POSTA.
      * CHAVE DE CONTA MONTADA A PARTIR DO MOVIMENTO.
           MOVE LCT-AGENCIA TO CNT-AGENCIA
           MOVE LCT-CONTA   TO CNT-NUM-CONTA
           READ CONTA-KSDS
               INVALID KEY
                   MOVE 'CONTA NAO ENCONTRADA' TO REG-AUDIT
                   WRITE REG-AUDIT
               NOT INVALID KEY
                   IF LCT-TIPO = 'C'
                       ADD LCT-VALOR TO CNT-SALDO-ATUAL
                   ELSE
                       SUBTRACT LCT-VALOR FROM CNT-SALDO-ATUAL
                   END-IF
                   REWRITE REG-CONTA
           END-READ.
