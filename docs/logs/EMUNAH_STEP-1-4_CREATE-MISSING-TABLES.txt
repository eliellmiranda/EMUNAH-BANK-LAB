 ISSUES ENCOUNTERED AND RESOLVED
 -------
 Issue 1: WITH DEFAULT '' — invalid in DB2 for z/OS
   Symptom: "SQLID expected" parse error from Developer Extension
   Root cause: Empty string literal '' is syntactically illegal in
               DB2 for z/OS DDL. Parser loses state and attempts to
               recover by reading next token as SET CURRENT SQLID.
   Fix: Replace WITH DEFAULT '' with bare WITH DEFAULT on all
        CHAR columns. Bare WITH DEFAULT on CHAR(n) = spaces.
   Affected: CDLCT (LCT_HISTORICO, LCT_CANAL)
             CDEXT (EXT_DESCRICAO, EXT_CANAL)
             CDAUD (AU_CHAVE_REF, AU_COMPLEMENTO)

 Issue 2: WITH DEFAULT CURRENT TIMESTAMP / CURRENT DATE
   Symptom 1: Developer Extension linter underlines second word,
              blocks execution with "SQLID expected"
   Symptom 2: CURRENT_TIMESTAMP (underscore) rejected by DB2 engine
              SQLCODE=-104, SQLSTATE=42601
   Root cause: Hercules DBD1 build does not accept CURRENT_TIMESTAMP
               (ANSI form). Developer Extension linter rejects the
               two-word DB2 form CURRENT TIMESTAMP at parse time.
               Neither form can pass both client and server.
   Fix: Remove WITH DEFAULT clause entirely. Make column nullable.
        COBOL programs will supply the value explicitly on INSERT.
   Affected: CDEXT (EXT_DT_CARGA) → TIMESTAMP nullable
             CDAUD (AUD_TIMESTAMP) → TIMESTAMP nullable
             CDAUD (AU_DATA_EVENTO) → DATE NOT NULL, no default
