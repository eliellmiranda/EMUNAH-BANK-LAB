📥 Importar Tickets

Selecione um arquivo .json com a lista de tickets no formato abaixo. Tickets com ticket_id já existente serão ignorados. 

[
  {
    "ticket_id": "EB-001-01",
    "titulo": "Título do ticket",
    "categoria": "incidente",
    "severidade": "alta",
    "dificuldade": "pleno",
    "tempo": "60min",
    "ferramenta": "SDSF / JES",
    "descricao": "Descrição detalhada...",
    "tags": ["cobol", "batch"],
    "status": "backlog",
    "dia": 1,
    "inj": null,
    "notas": ""
  }
]

📥 Importar Injeções

Selecione um arquivo .json com injeções customizadas no formato abaixo. Injeções com id já existente serão ignoradas. 

[
  {
    "id": "INJ-CUS-001",
    "titulo": "Título da injeção",
    "arquivos": ["EBVALI01.cbl"],
    "sintoma": "Sintoma observável no batch ou no spool...",
    "dica": "Dica de diagnóstico para o analista."
  }
]
