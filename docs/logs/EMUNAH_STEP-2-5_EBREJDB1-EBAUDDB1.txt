 EBAUDDB1 — COMPILE FIXES APPLIED

 1. IGYCB7309-W: Same recursive PERFORM pattern as EBREJDB1.
    FIX: Same guard-in-loop fix applied.
    DISPLAY for invalid records commented out to prevent spool flooding.

 2. FILE STATUS 37: ASSIGN AS-AUDSEQ -> AUDSEQ
    FIX: Removed AS- prefix. AUDIT.SEQ is PS/QSAM, not ESDS.

 3. FILE STATUS 39: FD record length mismatch
    ROOT CAUSE: ELIEL.EMUNAH.ARQ.AUDIT.SEQ was allocated with
    LRECL=18 (corrupted) then reallocated at LRECL=120 (wrong).
    Physical LRECL must be 128:
      - CPAUD001 fields = 120 bytes
      - FILLER PIC X(8) appended by writers (EBVALI01, EBPOST01) = 8 bytes
      - Physical record = 128 bytes
    FIX: CPAUD001 refactored to include the 8-byte FILLER internally.
    ELIEL.EMUNAH.ARQ.AUDIT.SEQ reallocated at LRECL=128.
    All writer programs (EBVALI01, EBPOST01, EBSNAP01, EBREPR01,
    EBEXTR01) must have their redundant FILLER removed and be
    recompiled before the chain runs.

 4. SQLCODE -180: Invalid date on AU-DATA-EVENTO
    FIX: Added date validation — if AU-DATA-EVENTO = ZEROS or SPACES
    or NOT NUMERIC, move '1900-01-01' to HV-AU-DATA-EVENTO as fallback.

 5. SQLCODE -545: CHECK constraint violation on AU_TIPO_EVENTO
    FIX: WHEN -545 added to EVALUATE — logs and continues without
    ROLLBACK so the rest of the file loads cleanly.
