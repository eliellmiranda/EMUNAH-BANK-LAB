 PHASE 1 ISSUES LOG (lessons learned)
 -------
 1. emunah.sql overwritten 4x with query text — use db2/scratch.sql
 2. WITH DEFAULT '' invalid in DB2 for z/OS DDL — use WITH DEFAULT
 3. CURRENT TIMESTAMP / CURRENT DATE blocked by VS Code linter AND
    rejected by Hercules DB2 engine — removed defaults, use nullable
 4. RACF DSNR profiles lost in backup recovery — must include in
    backup/restore checklist: DBD1.BATCH, DBD1.TSO permits for all
    DB2 users
 5. ALLOC FI(STEPLIB) restricted in TSO — use batch JCL for DB2
    load library allocation
 6. GRANT SQL cannot be issued at DSN prompt — use DSNTIAD via
    RUN PROGRAM(DSNTIAD) PLAN(DSNTIA13)
