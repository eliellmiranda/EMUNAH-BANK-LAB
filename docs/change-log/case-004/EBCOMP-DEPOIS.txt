//* ===================================================================
//* ARQUIVO      : EBCOMP.jcl
//* CAMINHO LOCAL: jcl/compile/EBCOMP.jcl
//* HOST / PDS   : Z77948.EMUNAH.DEV.JCL(EBCOMP)
//* ===================================================================
//* FINALIDADE:
//* Compilacao do programa COBOL EBCLLOAD.
//* Usa a procedure IBM IGYWCL que encapsula compile + linkage.
//*
//* FLUXO ESPERADO:
//* 1. Ler o fonte COBOL (EBCLLOAD).
//* 2. Resolver os copybooks (CPCLI001, CPCNT001).
//* 3. Compilar e link-editar automaticamente.
//* 4. Gerar o modulo executavel na LOADLIB.
//* 5. Emitir listagem e mensagens de compilacao.
//*
//* NOTA IMPORTANTE:
//* Esta versao usa IGYWCL (procedure catalogada IBM) em vez de
//* chamar IGYCRCTL diretamente. IGYWCL ja tem todos os STEPLIB
//* e configuracoes pre-definidas, eliminando o erro S806.
//* ===================================================================
//EBCOMP   JOB ,'EMUNAH COMP',CLASS=A,MSGCLASS=X,MSGLEVEL=(1,1)
//*
//* EBCOMP:
//*   Nome do job no JES2.
//* 'EMUNAH COMP':
//*   Descricao do job para identificacao no spool.
//* CLASS=A:
//*   Classe de execucao conforme regime do ambiente.
//* MSGCLASS=X:
//*   Classe de saida para exibicao posterior.
//* MSGLEVEL=(1,1):
//*   Exibe instrucoes JCL e mensagens de cada step.
//*
//* ===================================================================
//* STEP PRINCIPAL: COMPILACAO + LINKAGE (IGYWCL)
//* ===================================================================
//STEP1    EXEC IGYWCL
//*
//* IGYWCL:
//*   Procedure catalogada IBM que executa:
//*   1. Compilacao COBOL com IGYCRCTL
//*   2. Link-edicao com IEWBLINK
//*   3. Tudo ja com STEPLIB correto (nao precisa especificar)
//*
//* A procedure IGYWCL espera que voce defina os seguintes DDNAMEs:
//*   COBOL.SYSIN   = fonte COBOL
//*   COBOL.SYSLIB  = biblioteca de copybooks
//*   LKED.SYSLMOD  = biblioteca de carga (LOADLIB)
//*   LKED.SYSPRINT = relatorio do linkage (opcional)
//*
//* ===================================================================
//* CONFIGURACAO DA COMPILACAO (Secao COBOL)
//* ===================================================================
//COBOL.SYSIN   DD DSN=Z77948.EMUNAH.DEV.COBOL(EBCLLOAD),DISP=SHR
//*
//* SYSIN:
//*   Dataset contendo o fonte COBOL a compilar.
//* DSN=Z77948.EMUNAH.DEV.COBOL(EBCLLOAD):
//*   PDS Member com o programa EBCLLOAD.
//* DISP=SHR:
//*   Acesso compartilhado (leitura).
//*
//COBOL.SYSLIB  DD DSN=Z77948.EMUNAH.DEV.COPY,DISP=SHR
//*
//* SYSLIB:
//*   Biblioteca de copybooks que o compilador vai resolver.
//* Contem:
//*   - CPCLI001 (layout de clientes)
//*   - CPCNT001 (layout de contas)
//*   - Outros copybooks do escopo do projeto
//* DISP=SHR:
//*   Acesso compartilhado.
//*
//* ===================================================================
//* CONFIGURACAO DO LINKAGE (Secao LKED)
//* ===================================================================
//LKED.SYSLMOD  DD DSN=Z77948.EMUNAH.DEV.LOADLIB(EBCLLOAD),DISP=SHR
//*
//* SYSLMOD:
//*   Biblioteca de carga onde o executavel sera gravado.
//* DSN=Z77948.EMUNAH.DEV.LOADLIB(EBCLLOAD):
//*   O programa EBCLLOAD sera gravado como member em DEV.LOADLIB.
//* DISP=SHR:
//*   Acesso compartilhado. Se ja existir, sobrescreve.
//*
//LKED.SYSPRINT DD SYSOUT=*
//*
//* SYSPRINT:
//*   Relatorio detalhado do link-editor.
//* SYSOUT=*:
//*   Direcionado para impressao/spool imediato.
//*
//* ===================================================================
//* RESULTADO
//* ===================================================================
//* RC=0:   Compilacao bem-sucedida, executavel em LOADLIB
//* RC=4:   Compilacao com warnings (OK para prosseguir)
//* RC=8:   Erro na compilacao (revise SYSPRINT)
//* RC>12:  Erro grave (revise Fault Analyzer)
//* ===================================================================
